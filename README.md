# Digital Heritage in Video Games

Real historical places side by side with their versions in video games. The site
lets you search a place or a game, compare the real photograph with the in-game
view, browse by historical period, and follow every image and text to its source.

A project of Cantay Caliskan and Mija Aleksandraviciute, University of Rochester.

This repository holds the published website. It is generated by the `gameheritage`
Python package (`gameheritage website --out <this folder>`), which also keeps the
data tables, the matching pipeline and the credits for every image.

* `index.html`, `assets/`: the page, its script and styles
* `data/index.json`: games, places and in-game versions
* `data/places/<id>.json`: one file per place, with sources and credits
* `img/`: web-size copies of the photographs and game images

Photographs keep their own licences (listed with each image). Game images belong
to their publishers and are shown at reduced size for research, teaching and
commentary, with credit and a link to their source. Texts from Wikipedia and from
Fandom wikis are CC BY-SA; Wikidata facts are CC0. The site's code is MIT-licensed.
